# Egreter

Egreter 是基于 Egret Engine 现有代码继续建设的现代化游戏开发 SDK。

当前仓库正在从原 Egret v6 未完成实现向新的 Egreter 架构演进。新的产品命令行统一为 `egreter`，只支持 modern Egreter project，不以兼容 legacy Egret 项目为目标。
